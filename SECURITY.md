# Security policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private
vulnerability reporting feature for this repository when available. Otherwise,
contact the repository owner privately through their GitHub profile.

Include the affected version or commit, reproduction steps, impact, and any
suggested remediation. You can expect acknowledgement before any public
disclosure is coordinated.
